# ViewMD Product Positioning

Status: Approved
Date: 2026-06-05

## Positioning

**Beautifully read and export AI-generated Markdown on your Mac.**

## Hero

**Your AI gives you Markdown. ViewMD makes it readable.**

Open `.md` files directly on your Mac, review them in a polished document
view, and export a shareable PDF beside the original.

Primary CTA: **Download for Mac**

## Target User

The primary user is a non-technical Mac user who receives `.md` files from AI
conversations or terminal-based AI agents.

For the public beta, prioritize AI power users on Mac who already receive
Markdown from ChatGPT, Claude, Cursor, Codex, or agent workflows.

Their main jobs are:

1. Read AI-generated Markdown with finished-document typography.
2. Review the output before sharing.
3. Export a polished PDF into the same folder as the source file.

## Problem

The current workflow requires users to:

1. Search for an online Markdown viewer.
2. Upload a file or paste its contents.
3. Juggle browser tabs.
4. Accept ordinary formatting.
5. Download a PDF into Downloads.
6. Move the PDF back beside the source file.

ViewMD replaces this with:

1. Double-click the `.md` file.
2. Read it locally.
3. Click **Export PDF**.

## V1 Scope

- Native macOS Markdown reader.
- Local and offline by default.
- Beautiful, reader-first document rendering.
- PDF export beside the source file.
- Preserve the source basename: `report.md` becomes `report.pdf`.
- Confirm before overwriting an existing PDF.

## Not V1

- Rich-text editing.
- Full Markdown editing.
- Cloud uploads or synchronization.
- Collaboration features.
- Generic developer-tool positioning.

## Category

Lead with: **AI Markdown reader for Mac**

Public-beta launch mode: **local-first AI Markdown to PDF workflow**

Do not lead with:

- Markdown editor
- Developer tool
- PDF renderer
- Generic Markdown previewer

## Product Principles

- Solve the complete read-and-share workflow.
- Make Markdown feel like a normal Mac document.
- Keep user files private and local.
- Prefer obvious native behavior over configuration.
- Add editing only if observed usage proves it is necessary.
