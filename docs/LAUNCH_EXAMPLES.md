## Public-Quality Example Criteria

- The document should look like something a real user would receive from an AI tool.
- The subject should be easy to understand without explaining ViewMD.
- The file should include enough structure to show rendering quality: headings, bullets, tables, task lists, quotes, and ideally one code or data block.
- The content should not contain private, client, employer, or credential information.
- The exported PDF should be useful enough that someone might actually send it.
