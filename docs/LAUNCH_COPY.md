## r/MacApps

Title:

I made a Mac app for turning AI-generated Markdown into readable PDFs

Body:

I keep getting useful `.md` files from AI tools and agents, but the next step is usually annoying: open a browser previewer, paste or upload the file, export a PDF, then move it back to the right folder.

ViewMD is a small Mac app that handles that workflow locally:

- open `.md` files from Finder
- read them in a polished document view
- export `filename.pdf` beside `filename.md`
- keep file contents on your Mac

I built ViewMD and I am sharing the first public beta. It differs from general Markdown editors because it is focused on one local Mac workflow: open the AI-generated file, read it, and export a PDF beside the source file.

Important: this beta is unsigned and not notarized yet, so macOS will warn before opening it. The source is available if you would rather build locally.
